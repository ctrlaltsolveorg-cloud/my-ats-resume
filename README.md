# ATS Resume Studio & Builder

A high-performance, single-page, ATS-friendly interactive **Resume Builder web application** tailored for software engineering and product development roles.

Built with pure Vanilla HTML5, CSS3, and JavaScript — **0 dependency downloads, lightning fast, 100% lightweight.**

## 🚀 Key Features

1. **Strict 1-Page A4 ATS Output**: Clean single-column layout optimized for Applicant Tracking Systems (ATS) with no photos, visual progress bars, tables, or decorative graphics that disrupt ATS parsing.
2. **Live Interactive Split Editor**: Real-time form controls on the left update the A4 paper canvas on the right instantly.
3. **Smart A4 Page Fit Indicator**: Built-in height detector with density toggles (`Standard`, `Compact`, `Ultra Tight`) ensuring content stays on exactly 1 printable A4 page.
4. **1-Click PDF Export & Print Engine**: Dedicated `@media print` CSS block formats only the A4 resume when downloading as PDF or printing (`window.print()`), hiding all web UI controls.
5. **Clickable PDF Links**: Preserves native clickable `mailto:` and `https://` URLs for email, LinkedIn, and GitHub in exported PDFs.
6. **Data Privacy & Auto-Save**: Saves content locally to `localStorage`. Includes a 1-click **Reset Default Resume** button.

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3 (CSS Variables, Flexbox/Grid, `@media print`), Vanilla JavaScript (ES6+).
- **Deployment**: GitHub Pages / Static Hosting.
